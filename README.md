# cascadeguard-exemplar-web-cloudflare

A minimal nginx web app container demonstrating the CascadeGuard CLI-first workflow with GitHub CI and Cloudflare as the deployment target.

This is a companion to the CascadeGuard public how-to guide. Every step below was performed using the CLI — manual edits were avoided where the tooling allowed.

## Step-by-step: how this was set up

### Prerequisites

- [CascadeGuard CLI](https://github.com/cascadeguard/cascadeguard) installed
- A GitHub repo created (this one)
- Write access to GHCR under the `cascadeguard` org

### 1. Enrol the image

Use the CLI to register the image in `images.yaml`. Note: `--images-yaml` is a flag on the `images` parent command, not on `enrol` directly:

```bash
cascadeguard images \
  --images-yaml images.yaml \
  enrol \
  --name exemplar-web-cloudflare \
  --registry ghcr.io \
  --repository cascadeguard/exemplar-web-cloudflare \
  --provider github \
  --repo cascadeguard/cascadeguard-exemplar-web-cloudflare \
  --dockerfile Dockerfile \
  --branch main \
  --rebuild-delay 7d
```

This produces the `images.yaml` at the root of this repo.

> **CLI friction noted (D6 gap):** The `--images-yaml` flag must appear *before* the subcommand name (`enrol`), not after it. This is unintuitive and easy to get wrong. Also, there is no `--auto-rebuild` flag; `autoRebuild: true` must be added manually if desired.

### 2. Create the container image

`Dockerfile` extends `nginx:1.28.3-alpine3.23` and copies in `index.html`:

```dockerfile
FROM nginx:1.28.3-alpine3.23
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
```

### 3. GitHub Actions CI/CD

The workflows in `.github/workflows/` were written to match the standard CascadeGuard CI pattern:

- **`ci.yaml`** — triggered on push to `main` and on PRs; builds the image, scans with Grype and Trivy, and pushes to GHCR on `main` merges.
- **`build-image.yaml`** — reusable `workflow_call` that handles build, scan, SBOM generation, and Cosign signing.
- **`scheduled-scan.yaml`** — nightly CVE re-scan of the published image; opens a GitHub issue on failure.
- **`enforce-actions-policy.yaml`** — validates all workflow files against `.cascadeguard/actions-policy.yaml` on every PR.

The image is published to: `ghcr.io/cascadeguard/exemplar-web-cloudflare:latest`

### 4. Actions policy

`.cascadeguard/actions-policy.yaml` mirrors the policy used in other CascadeGuard repos. All actions must be pinned to a full commit SHA in the workflows.

## Cloudflare Containers evaluation

> **Evaluation date:** April 2026

[Cloudflare Containers](https://developers.cloudflare.com/containers/) allows Docker containers to run on Cloudflare's global network, integrated with the Workers runtime.

### Verdict: viable, with caveats

nginx running on port 80 is a well-supported use case. Cloudflare handles TLS termination so the container only needs to serve plain HTTP. The deployment is straightforward once authentication is configured.

### Deployment steps (manual)

1. Install Wrangler: `npm install -g wrangler`
2. Authenticate: `wrangler login`
3. Create `wrangler.toml`:

```toml
name = "exemplar-web-cloudflare"
compatibility_date = "2025-07-01"

[containers]
image = "ghcr.io/cascadeguard/exemplar-web-cloudflare:latest"
```

4. Deploy: `wrangler deploy`

Cloudflare pulls the image from GHCR. The container listens on port 80; Cloudflare routes traffic and terminates TLS.

### Gaps and notes

| Gap | Detail |
|-----|--------|
| **Actions policy** | `cloudflare/wrangler-action` is not in the CascadeGuard allowed-actions list. Automated CD to Cloudflare requires a policy update or manual deployment. |
| **Image visibility** | GHCR images must be public or Cloudflare must be granted pull access. |
| **Paid plan required** | Cloudflare Containers requires a Workers paid plan. |
| **Platform maturity** | Cloudflare Containers was in public beta as of mid-2025. Check [docs](https://developers.cloudflare.com/containers/) for current GA status. |

> **D6 gap filed:** `cloudflare/wrangler-action` needs to be added to the standard CascadeGuard actions policy allowlist before automated Cloudflare CD can be implemented in a compliant workflow.
